# recanto — página de download

Página estática (um `index.html`, sem build) com o link do instalador do **recanto**, o app de chat, voz e
compartilhamento de tela que eu rodo pros amigos.

O instalador **não** mora aqui: são ~109 MB, acima do limite do GitHub Pages. O botão aponta pro próprio
servidor do recanto, que já serve esses arquivos pro auto-update do app. A página lê o `latest.yml` de lá
ao abrir, então versão, tamanho e link se atualizam sozinhos quando uma versão nova sobe.

O código do app fica em outro repositório (privado).
